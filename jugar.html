Jugar

Haz clic dentro del recuadro y pulsa Enter para empezar. Se juega con el teclado, así que funciona en computador, no en celular. La primera vez puede tardar unos segundos en cargar.

Controles: flechas o A/D para moverse, Espacio para saltar, Esc para pausar y R para reiniciar.

Descargar para Windows

Si prefieres jugar sin navegador, descarga el ejecutable, descomprímelo y abre SpaceshipUltimate.exe. Funciona en Windows 10 u 11 de 64 bits.
